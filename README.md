# Ejercicios-SENATI

Repositorio de ejercicios y práctica del curso de Python aplicado a Machine Learning (SENATI).

## Estructura del repositorio

- **DOCUMENTACION TEORICA/** — Resúmenes en markdown de la teoría vista en cada sesión de clase (Pandas, NumPy, Scikit-learn, TensorFlow, Keras, Matplotlib, Seaborn, seminarios, etc.).
- **TensorFlow-Keras Estudio/** — Notebooks propios de estudio sobre TensorFlow/Keras (clasificación binaria, regresión, plantillas de referencia y clasificación multiclase), con teoría explicada paso a paso.
- **IA_PRIMEROS_PASOS/** — Primeros ejercicios introductorios de Inteligencia Artificial.
- **NLP PRACTICAS/** — Prácticas de Procesamiento de Lenguaje Natural (tokenización, TF-IDF, spaCy, Transformers).
- **PANDAS_1/** y **PADAS+POGRESS/** — Ejercicios y avances de la biblioteca Pandas.
- **SKL_PRACTICA SENATI/** — Prácticas con Scikit-learn.
- **TRANSFORMERS PRACTICAS/** — Prácticas con la biblioteca Transformers (Hugging Face).
- **TRABAJO_FINAL_IA/** — Trabajo final del curso.
- **Claude outputs/** — Documentos generados con ayuda de IA (prompts, guiones, materiales de estudio). No se sube a control de versiones más que como referencia personal.

## Cómo ejecutar los notebooks

1. Instalar dependencias:
   ```bash
   pip install tensorflow numpy scikit-learn notebook
   ```
2. Abrir el notebook deseado en Jupyter, VSCode, o el editor de tu preferencia.
3. Ejecutar las celdas en orden (de arriba hacia abajo).
