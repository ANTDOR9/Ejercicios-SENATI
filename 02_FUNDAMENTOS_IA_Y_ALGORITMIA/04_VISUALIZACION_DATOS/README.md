## 🎯 Objetivo

Generar reportes estadísticos con pandas (`max`, `count`, `mean`, `sum`, `groupby`, `merge`) y representarlos con gráficos de Matplotlib y Seaborn.

## 📂 Contenido

| Archivo | Tema |
|---|---|
| [`01_merge_conteo_barras_torta.ipynb`](01_merge_conteo_barras_torta.ipynb) | `merge` entre tablas, conteo por familia, gráfico de barras, torta y `subplots` |
| [`02_reporte_ventas_groupby.ipynb`](02_reporte_ventas_groupby.ipynb) | Funciones de varias filas, filtros por vendedor y `groupby` con gráfico de barras |
| [`03_histogramas_propinas_tips.ipynb`](03_histogramas_propinas_tips.ipynb) | Dataset `tips` de Seaborn: histogramas y reportes por sexo |
| [`04_reporte_ventas_por_vendedor.ipynb`](04_reporte_ventas_por_vendedor.ipynb) | Suma y promedio por vendedor combinados en un gráfico |

## 🗒️ Conclusión

El flujo se repite: estructurar el reporte (`groupby`), separar etiquetas (`.index`) y valores (`.values`), y graficarlos.
