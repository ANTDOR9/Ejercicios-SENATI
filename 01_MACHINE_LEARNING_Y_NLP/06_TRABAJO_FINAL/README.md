## 🎯 Objetivo

Integrar en un solo proyecto lo aprendido durante el curso: manipulación de datos (Pandas), entrenamiento de modelos (Scikit-learn / TensorFlow) y, según el caso, procesamiento de texto (NLP/Transformers), aplicado a un caso de datos de mercado financiero.

## 📖 Contenido de la carpeta

- `datos_mercado_financiero.csv` — dataset con el que trabaja el proyecto.
- `generar_datos.py` — script que genera/simula el dataset.
- `proyecto_final.ipynb` — notebook con el desarrollo completo del proyecto.

## 🗒️ Nota

Este es el cierre práctico del curso: aplica en conjunto los conceptos de las sesiones anteriores (carga y limpieza de datos, entrenamiento de un modelo, evaluación de resultados) sobre un caso más realista que los ejercicios sueltos de cada sesión.
